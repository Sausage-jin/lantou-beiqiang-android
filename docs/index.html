一句话说明:本应用是纯本地运行的休闲棋牌游戏,不收集、不上传、不共享任何个人信息,没有账号、没有广告、没有第三方统计 SDK。

一我们收集的信息

本应用不收集任何个人信息。您无需注册或登录账号,我们也不会获取您的姓名、手机号、邮箱、设备标识符(IMEI / MAC / Android ID / OAID 等)、位置、通讯录、相册、通话记录、短信或已安装应用列表。

二设备本地存储

应用仅在您的设备本地保存游戏偏好设置(音乐 / 音效开关及音量),用于下次启动时恢复您的设置。这些数据仅存放在本机、不上传至任何服务器,卸载应用即被清除,我们无法读取。

游戏对局进度仅存在于当前运行的应用内存中,退出对局后不留存。

三权限说明

本应用仅申请以下两项系统权限,且用途单一:

  • INTERNET — 仅用于「局域网联机对战」:由您主动输入对方设备 IP 地址后,在两台设备之间建立直连,传输对局操作数据。
  • ACCESS_WIFI_STATE — 仅用于判断当前网络状态,以判断能否进行局域网联机。
应用不连接开发者或任何第三方的服务器,不会向互联网上传任何数据;联机对战数据仅在参与对局的两台设备之间传输,不经过、也不存储于任何服务端。若您不使用联机功能,该功能不会产生任何网络通信。

四第三方服务

本应用未集成任何第三方 SDK,包括但不限于统计分析、广告、推送、支付、社交登录、崩溃上报、地图与人工智能服务;应用内不含广告,不含应用内购买,不含外链跳转或用户生成内容发布功能。

五信息的共享、转让与公开披露

由于我们不收集任何个人信息,因此不存在向任何第三方共享、转让或公开披露个人信息的情况,也不会将相关信息用于用户画像或自动化决策。

六数据安全

应用不设置远端数据接口,不存在数据传输、存储或泄露的服务端环节。局域网联机由用户自行发起,通信内容仅含对局所需的牌面与操作指令,不含任何身份类信息。建议您仅在可信的局域网环境中使用联机功能。

七未成年人保护

本应用为无账号、无社交、无聊天功能的休闲棋牌游戏,不面向儿童收集任何个人信息,也不会基于个人信息进行定向推荐。若您是未成年人,请在监护人指导下使用本应用。

八账号注销与数据删除

本应用不提供账号体系,因此不存在账号注册与注销流程。如需清除全部本地数据,直接在系统设置中卸载本应用或清除应用数据即可。

九隐私政策的更新

如因功能调整需要更新本政策,我们将在本页面公布更新后的内容并修改「最近更新」日期。涉及个人信息处理方式的重大变更,会在应用内以显著方式提示。
